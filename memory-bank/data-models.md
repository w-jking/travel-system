# 数据模型清单（阶段一）

本清单用于对齐核心实体、字段、关系与枚举，作为后续数据库与接口设计依据。

## 1. 实体与字段

### 1.1 员工（Employee）

必填字段：  
- 姓名  
- 手机号  
- 部门  
- 岗位  
- 角色  
- 状态  

可选字段：  
- 邮箱  
- 入职日期  
- 工号  

### 1.2 客户（Customer）

必填字段：  
- 姓名  
- 联系方式  
- 客户等级  
- 负责人  

可选字段：  
- 证件号  
- 出生日期  
- 旅游偏好  
- 历史订单备注  

### 1.3 订单（Order）

必填字段：  
- 客户  
- 订单金额  
- 收款主体  
- 状态  
- 负责人  
- 下单日期  

可选字段：  
- 出团日期  
- 产品线路  
- 备注  

### 1.4 回访记录（FollowUp）

必填字段：  
- 客户  
- 回访时间  
- 沟通方式  
- 主要诉求  
- 结果  
- 负责人  

可选字段：  
- 下次回访时间  
- 附件说明  

### 1.5 角色（Role）

必填字段：  
- 角色名称  
- 权限集合  
- 状态  

可选字段：  
- 描述  

### 1.6 权限（Permission）

必填字段：  
- 资源  
- 动作  
- 作用范围  

### 1.7 操作日志（AuditLog）

必填字段：  
- 操作人  
- 时间  
- 操作类型  
- 对象类型  
- 对象标识  
- 变更摘要  

可选字段：  
- 变更前后字段快照  

### 1.8 导出审批（ExportApproval）

必填字段：  
- 申请人  
- 申请时间  
- 数据范围  
- 审批状态  
- 审批人  

可选字段：  
- 审批意见  

### 1.9 退款审批（RefundApproval）

必填字段：  
- 订单  
- 申请人  
- 申请时间  
- 审批状态  
- 审批人  

可选字段：  
- 审批意见  

### 1.10 登录账号（AuthAccount）

必填字段：  
- 员工  
- 账号  
- 密码  

## 2. 关系说明

- 员工与客户：一名员工负责多个客户  
- 客户与订单：一个客户可对应多个订单  
- 订单与回访记录：订单可触发多次回访记录  
- 角色与权限：一角色包含多个权限  
- 操作日志关联：操作日志关联员工与目标对象  
- 审批记录：导出与退款审批关联申请人、审批人及目标对象  

## 3. 枚举与规则

- 订单状态：待确认、已收款、已出团、已完成、已取消  
- 订单状态跳转：允许在以上状态间按业务需要直接跳转，必须记录原因  
- 客户等级：普通、VIP  
- 员工状态：在职、离职、试用期  
- 审批状态：待审批、已通过、已拒绝
